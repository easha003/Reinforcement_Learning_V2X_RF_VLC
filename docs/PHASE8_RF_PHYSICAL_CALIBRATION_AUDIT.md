## Purpose

The RF-decoding scaling diagnostic found that the optimistic propagation floor
first passes at the declared `2x` improvement point, with a continuous limiting
threshold of `1.620462x`. This audit checks whether that abstract reduction can
already be assigned to a defensible coding, MCS, power, or diversity
configuration.

This is a read-only configuration audit. It did not replay traces, evaluate a
policy, start training, or open the held-out test split.

## Active link calculation

The live environment uses the complete 24-RB, 10-MHz resource grid for each RF
attempt. After 40% overhead, one 0.5-ms slot carries 9,676.8 coded bits. With
16QAM, the finite-blocklength approximation therefore receives 2,419 complex
channel uses and 2,784 information bits, an information rate of 1.150889 bits
per channel use.

| Conditional BLER target | Required SNR |
|---:|---:|
| `1e-1` | `1.035985 dB` |
| `1e-3` | `1.292368 dB` |
| `1e-4` | `1.380845 dB` |
| `1e-5` | `1.457377 dB` |

An older unit test divided the configured grid by QPSK's two bits per resource
element and asserted 4,838 channel uses even though the active configuration is
16QAM. That test did not construct the live environment, so the completed
frontiers used the correct 2,419-use model; the stale test and its derived
margin/outage expectations have now been corrected.

## Blocking resource-semantics finding

The propagation and collision models currently describe different allocation
units:

| Quantity | Active value |
|---|---:|
| System grid | 24 RB over 10 MHz |
| Collision-pool claim | two 12-RB subchannels |
| Link allocation per attempt | 24 RB |
| Configured coded block | 8,352.008 bits |
| Capacity of one 12-RB subchannel | 4,838.4 coded bits |
| Minimum code rate needed to fit the block in 12 RB | `0.575397` |
| Current configured code rate | approximately `1/3` |

Thus one active link allocation spans both collision-model subchannels. The
same attempt cannot simultaneously occupy all 24 RB for BLER and only one of
two 12-RB choices for collision. The configured rate-1/3 block fits the full
carrier but does not fit one 12-RB subchannel in one slot.

The declared RF calibration path,
`artifacts/calibration/rf/mode2-v1`, is also absent. The analytical collision
model is intentionally not presented as calibrated NR Mode 2, but the missing
artifact means it cannot supply the evidence needed to resolve this mismatch.

## Interpretation of physical knobs

- **Transmit power:** the active 23 dBm already equals the nominal n47
  power-class-3 value. The allowed production tolerance is not design
  headroom, so a power increase is not frozen as the `2x` intervention.
- **Coding/MCS within 12 RB:** fitting the same block into one subchannel would
  require code rate at least `0.575397`, reducing redundancy and doubling the
  information rate to about 2.303 bits per channel use. That moves decoding
  reliability in the wrong direction and must be recalibrated rather than
  called a `2x` improvement.
- **Full-carrier allocation:** keeping 24 RB per attempt preserves the live
  link calculation, but a 10-MHz carrier then contains one frequency resource
  per slot, not two. The capacity levels previously labeled 10, 20, and 40 MHz
  must become 1, 2, and 4 full-carrier resources, respectively.
- **Independent receive diversity:** a second independently fading receive
  branch could lower decoding risk without exceeding the 23 dBm transmit-power
  anchor, but antenna gain, combining rule, and branch correlation are not yet
  configured or calibrated. It remains a candidate, not evidence.

## Decision and minimal next path

The physical-profile freeze is **not ready**, and training remains blocked.
Treating the abstract `2x` divisor as a deployable radio would hide both the
allocation mismatch and the missing diversity calibration.

The minimal defensible path is:

1. Freeze one full 10-MHz carrier per RF attempt, because that matches the
   channel model that produced every existing propagation result.
2. Correct the collision capacity mapping to 1, 2, and 4 full-carrier resources
   for 10, 20, and 40 MHz. The earlier 2/4/8 collision cells remain sensitivity
   results but not those bandwidth labels.
3. Predeclare an independent receive-diversity frontier with explicit antenna
   count, combining rule, gain/correlation assumptions, and sensitivity bands.
   This declaration is now complete; it is literature-bounded synthetic
   calibration, not on-road field validation.
4. Re-run only the affected certificate-aware feasibility frontier. Mobility
   traces, state-regime audits, and the abstract zero-contention RF-scaling
   diagnostic do not need to be regenerated.

No physical parameter was changed by this audit. Items 1--3 are now frozen.
The next task is to implement and verify the declared second-branch fading and
MRC calculation before item 4 is executed.
